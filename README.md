# Euphoria

Free, open source key, tempo and energy analysis for DJ libraries. A desktop app and a CLI over one shared core, written in Rust.

Euphoria reads a folder of tracks, finds the key (Camelot and musical notation), the tempo and an energy rating for each one, then writes the results into file tags and exports to rekordbox so they show up in your DJ software. It runs fully offline, with no account and no activation.

## Status

Early development. The first step is an accuracy benchmark that decides which key and tempo detectors go into the core.

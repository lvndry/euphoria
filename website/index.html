More tracks with the exact key than KeyFinder.

Euphoria finds keys with drone-v2, a neural network the project trained and built into the app. On 604 dance tracks it names the exact key 69.9% of the time, against 60.6% for KeyFinder, the free key detector also built into Mixxx DJ.

Unsure tracks, in one list

A key or tempo rated low confidence, or a key that disagrees with the file's tags, lands under Needs review. Play the key's notes on the keyboard and decide.

  • Shift a track's key and hear what it mixes with there
  • Correct the key, tempo or energy in one place

Every change, shown before it happens

Euphoria lists each file and each field before writing tags. Keys and tempos already in your files are kept, unsure values are skipped, and undo puts the old tags back byte for byte.

Running in under a minute.

One command installs the app and the command line tool, after checking every file against the release's checksums. Run it again to upgrade.

curl -fsSL https://github.com/lvndry/euphoria/releases/latest/download/install.sh | sh

Puts euphoria in ~/.local/bin and the app in Applications on macOS, or as a launcher entry on Linux. Add --cli-only or --app-only with sh -s --, and run it with --uninstall to remove exactly what it installed.

brew tap lvndry/euphoria
brew install --cask euphoria

Download Euphoria.dmg, open it and drag Euphoria onto Applications. Releases are signed and notarized by Apple, so it opens normally.

Questions.

Is it really free? Yes. Euphoria is open source under the GPL-3.0, with no account, no trial and no licence key.

Does my music leave my computer? No. All analysis runs locally and works offline.

How is it different from Mixed In Key? It is an open alternative to paid harmonic mixing tools: the same job of finding keys, tempos and energy, free and inspectable.

Which DJ software does it work with? rekordbox through XML, Traktor through NML, Serato through file tags, and Engine DJ and VirtualDJ by writing into their libraries after saving a copy.

Are those exports tested? The rekordbox export is. The others are not yet tested inside each program, so keep the copy Euphoria saves.

Will it overwrite my tags? Only after showing every change. Existing keys and tempos are kept by default, and undo restores the old tags byte for byte.

How accurate are the keys? On the 604 GiantSteps Key previews, drone-v2 names the exact key for 69.9% of tracks and the key or its runner-up for 80.8%. The full results, misses included, are in the accuracy documentation.

What if a key is wrong? Unsure keys and tempos go to Needs review. Check them by ear on the keyboard and correct them in one click.

Can I script it? Yes. euphoria analyze prints a table or JSON, and every export is a command.

What about Windows? Releases are built for macOS on Apple Silicon and Linux on x86_64 today.

How do I update or remove it? Run the install script again to upgrade, or with --uninstall to remove exactly what it installed.

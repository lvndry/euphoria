# Logo

The mark is the curve two notes a perfect fifth apart trace on an oscilloscope: a Lissajous figure with a 3 to 2 frequency ratio. The fifth is the interval behind every neighbouring move on the Camelot wheel.

| File | Use |
| --- | --- |
| `mark.svg` | Black mark on a transparent background |
| `mark-white.svg` | White mark, for dark backgrounds |
| `app-icon.svg` | Application icon, 1024 px, white mark on the app's dark background |
| `favicon.svg` | Favicon, with a heavier line so it holds at 16 px |

The curve is `x = sin(3t)`, `y = sin(2t + 90 degrees)` for one full turn of `t`.
